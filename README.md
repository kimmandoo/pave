# Pave

![Pave logo](assets/pave-mark.svg)

Pave is an OCaml terminal coding agent for iOS, Android, Flutter and React Native repositories. Provider/agent core, a session journal and a keyboard-driven TUI run today; cancellation, LSP/DAP, subagents, plugins, a model catalog and many tools are not yet implemented. See `TASKS.md` for feature status.

## Install

Prebuilt releases support macOS 15+ (Apple Silicon and Intel) and glibc-based Linux with glibc 2.35+ (x86-64 and ARM64). Windows and musl Linux are not supported. Install or upgrade without opam or sudo:

```sh
curl -fsSL https://raw.githubusercontent.com/kimmandoo/pave/main/install.sh | sh
```

The installer downloads the matching release archive over HTTPS, verifies its SHA-256 digest against `SHA256SUMS`, and installs `pave` to `~/.local/bin` with its license notices in `~/.local/share/licenses/pave`. Ensure `~/.local/bin` is on your `PATH`; the installer prints a reminder when it is not. For a chosen release or destination, run `curl -fsSL https://raw.githubusercontent.com/kimmandoo/pave/main/install.sh | PAVE_VERSION=v0.1.0 PAVE_INSTALL_DIR=/absolute/path/bin sh`. Review [install.sh](install.sh) before piping it to a shell. Releases are generated by [the tag workflow](.github/workflows/release.yml); until its first version-tag build succeeds, use the source installation below.

<details><summary>Build and install from source (macOS/Linux)</summary>

Prerequisites: Git, curl, [opam](https://opam.ocaml.org/doc/Install.html), a C compiler, and the platform's usual build tools. On macOS, `brew install opam curl git` installs the CLI prerequisites (Xcode Command Line Tools supply the compiler). On Ubuntu/Debian, use `sudo apt-get install opam curl git build-essential pkg-config m4`. Other Linux distributions can use the opam installation guide. Run `opam init -y` once if opam has not been initialized.

```sh
git clone https://github.com/kimmandoo/pave.git
cd pave
opam switch create . 5.5.1 -y
opam install . --deps-only -y
opam install . -y
opam exec -- pave --help
```

The local opam switch is confined to the checkout; `opam exec --` uses it without changing the parent shell. CI targets OCaml 5.3 and 5.5; the source installation was exercised with 5.5.1. To run directly from source without installing the `pave` package, use `opam exec -- dune exec pave -- --root /path/to/mobile/repo` after the dependency step. To update, run `git pull --ff-only`, `opam install . --deps-only -y`, then `opam reinstall pave -y` from the checkout. To uninstall the source package, run `opam remove pave -y` in its switch; do not remove a shared switch.

</details>

For a prebuilt installation, rerun the installer to upgrade. To uninstall it, remove `~/.local/bin/pave` and `~/.local/share/licenses/pave` (or the corresponding custom installation paths).

## Run

Set `OPENAI_API_KEY` in the environment for the default provider, or `ANTHROPIC_API_KEY` for `--provider anthropic`. Never store keys in a session or checked-in config.

```sh
pave --root /path/to/mobile/repo --session /private/path/pave.jsonl
# one-shot:
pave --root /path/to/mobile/repo --prompt 'Inspect the Android build failure'
```

On a real terminal, interactive mode opens a resize-aware full-screen UI with a Unicode composer, bounded visible transcript, error/status line and live stream updates. Arrow keys move the cursor; Up/Down browse prompt history; Backspace/Delete edit Unicode text; Shift+Enter or bracketed paste inserts a line break; Ctrl+C clears the draft; Ctrl+D exits on an empty draft. `/help` lists commands. Redirected input or output keeps the plain line-oriented CLI. The UI redraws on input or output events rather than polling; while a model request is in flight, cancellation and queued typing are not yet supported. A session file retains the complete transcript even after the visible UI's last 240 rows roll off.

`--provider openai` (default) uses an OpenAI-compatible `/v1/chat/completions` endpoint and `OPENAI_API_KEY`; `--provider anthropic` uses `/v1/messages` and `ANTHROPIC_API_KEY`. `--endpoint URL` overrides the selected provider's default. `--model ID` defaults to `gpt-4.1-mini` for OpenAI and is required for Anthropic. `--stream` renders live text deltas from either protocol; without it responses are buffered. `--session /private/path/session.jsonl` writes an append-only, parent-linked JSONL conversation journal across runs. Existing flat JSON-array sessions are migrated on first open. Journals are private on creation but not encrypted; keep them outside version control because tool output can contain source or secrets. Interactive commands: `/entries` lists message IDs, `/branch ID` selects an earlier message and starts a new branch, `/fork /path/new.jsonl` copies the selected conversation into a new session, and `/exit` or `/quit` leaves the CLI. Restarting after an interrupted tool call records an error result for each unresolved call; it does **not** rerun the tool.

`/compact` asks the configured model to summarize completed earlier turns, then appends a compaction marker. Future requests replay that summary plus the latest user turn and later messages; the original branch entries remain available through `/entries` and `/branch`. The summary request sends the earlier transcript to the configured provider and can fail if it exceeds that model's context limit. A failed or empty summary never changes the journal. Compaction is manual; automatic context-window management, provider-native compaction and multimodal preservation are still pending.

Anthropic example (set `MODEL_ID` to a model supported by your account): `ANTHROPIC_API_KEY=... dune exec pave -- --provider anthropic --model "$MODEL_ID" --stream --root /path/to/repo`.

File browsing, search, exact-match edit and atomic write tools are available in the selected workspace. `mobile_project` identifies repository manifests and suggests relevant host-native build/test commands; it does not install SDKs or deploy apps. Model-requested shell execution is **off by default**. `--allow-shell` offers each command for explicit approval in an interactive terminal. Noninteractive sessions deny commands, even with the flag. Approved commands run without an OS sandbox and can access files outside the workspace; inspect each command before approving it. Never approve signing, device deployment, destructive operations or credential access without intending that effect.

Run `dune runtest` for protocol, workspace, stream framing, and end-to-end local HTTP tool-call tests. The agent stops after 20 model turns per prompt by default (`--max-turns`). Provider wire support currently covers OpenAI-compatible Chat Completions and Anthropic Messages (including SSE). OpenAI Responses/Codex, Gemini-native, other provider APIs and a model catalog are **not yet supported**. See `docs/DESIGN_RULES.md` for the contract.
