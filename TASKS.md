# Tasks — remaining work

Only unchecked, independently verifiable work belongs here. The completed implementation and release history remain in Git, `CHANGELOG.md` and `docs/WORK_CHECKPOINT.md`; do not reopen them through an umbrella parity checkbox. Pave already has provider-bound routes and discovery, account selection, journal recovery, worktrees, read/edit/search/bash, LSP/DAP, persistent approved JS/Python eval, bounded web/SSH tools, and a typed terminal/event loop. The sibling the behavioral reference is a **behavior reference**, not proof of Pave capability, provider entitlement, an authorized OAuth grant, a deployable hosted service, or a requirement to port Bun/Rust/N-API code.

**Working rule:** Finish one card at a time: preserve `docs/DESIGN_RULES.md`, exercise positive and misleading/denied cases in focused behavior tests, smoke changed CLI/tool/PTY paths, and update user-facing documentation and the changelog when behavior ships. Fixtures cannot establish live vendor entitlement, platform SDK availability or a real device run. Shell commands, spawned tools and mobile project-code execution retain exact interactive approval; headless approval-required effects fail closed. Dependencies below gate only named cards. R12 is complete and recorded in `CHANGELOG.md` and `docs/WORK_CHECKPOINT.md`; M01–M24 are the next mobile cards. R13–R16 remain independent release-track deliverables, not completion checkboxes.
